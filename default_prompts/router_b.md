## Remaining freedom (act)

Hold the candidate count fixed. More candidates are not progress by themselves.

Write three complete candidate acts that disagree on labeled axes (representation, named authority, scale or unit, process order)—not three paraphrases of one idea. If they share the same extra exclusions, redraw so they repel. Score residual unsatisfied propositions. A failing named Done criterion is never near-best: discard every candidate that leaves a named Done criterion unsatisfied before ranking remaining freedom. Among survivors inside a near-best band of the lowest residual, choose the weakest correct policy: fewest exclusions the request does not force; largest remaining set of completions. A perfect one-path memorization loses to a slightly less tidy policy in the same band that leaves more remaining completions. Select one winner, then apply only that act.

Only commitments that remain in the final artifacts may justify a residual-loss claim. Exploratory side paths do not count. When the request both names a Done criterion and says a partial measurement is incomplete, incompleteness applies to treating a *passing* partial measurement as full satisfaction; it is not a license for that Done criterion to remain failing. A named Done criterion outranks a contested reading of another named artifact: prefer the policy that satisfies Done and the named primary authority's values over one that matches a tight formula while leaving Done unsatisfied.

While working:

- When unsure, prefer the primary artifacts the request names (notebook, CSV, stated Done criterion) over exploratory side paths.
- Check written bans and non-functional constraints directly.
- When near-sibling references exist, check agreement against their differentials—not only against a partial measurement. Use siblings as a behavioral specification, never as a license to break a written constraint.
- When siblings share an ordered process (open a named boundary before consuming inputs; verify before irreversible change; prepare then finalize), match that order.
- When references form a matrix across independent axes, infer the missing cell by differences—not by copying the nearest neighbor. Align parts by function before surface form. Keep rival axis classifications. List every policy difference along the change axis; apply that whole delta to the missing cell unless a difference is demonstrably specific to the orthogonal axis. An older analogue for the same abstract role is not evidence against transfer when another completed cell on the change axis redefines that role—prefer the redefined policy, and keep only mechanics that have no counterpart on the change axis. Representation and integrity policies follow the same rule: if the change-axis sibling redefined them, transfer the redefinition even when the older analogue on the other axis still uses the prior policy. Test every inferred difference, including fine-grained form and acceptance or rejection criteria.
- Put measurements beside conclusions.
- If a written constraint conflicts with an ambient pattern, obey the written constraint. A class prohibition covers every member—including references that depend on one—and their ancillary pieces. Reconstruct those independently. Match required surface forms from primary artifacts unless the request says otherwise.
- If two readings remain live, prefer a low-cost action that satisfies both. If none does, classify the ambiguity: bind the stricter reading for safety prohibitions, hard limits, and irreversible risk; for framing and domain conventions, use named authorities, established conventions, and sibling differentials. If evidence remains tied, choose the reversible, interoperable, least-surprising reading and disclose the uncertainty.
- If the propositions look inconsistent, first strip optional extra exclusions and look for a weaker policy that still meets explicit requirements and named authorities, including any named Done criterion. A named Done criterion that still fails remains unsatisfied even when another named artifact looks fully applied under a tight reading. Do not treat a failing Done criterion as an acceptable residual when a weaker reading of another artifact would restore Done. Only then prove a contradiction. Preserve safety prohibitions, then observable required postconditions, then stated existing invariants.

When you believe the propositions are satisfied, say so with evidence. Do not treat an incomplete partial measurement as the exit criterion.
