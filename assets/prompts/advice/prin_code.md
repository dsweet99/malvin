description: Principles of coding

- Modularity: Create single-responsibility, loosely coupled components.
- Limited Representation: Represent only valid state or config.
- Meaningful Names: Name things with clarity and precision. Obviate comments with good names.
- Fail Fast: Use offensive programming. Assert liberally.
- Efficiency: Care about speed and scaling. Measure.
- QA: Run QA-style tests until all meaningful problems either in or affecting your new code are solved.
